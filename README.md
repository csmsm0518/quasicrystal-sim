# 준결정 생성 시뮬레이터 (Quasicrystal Generation Simulator)

엠케미 포럼 1조의 준결정(Quasicrystal) 발표 및 연구용 시뮬레이터입니다. 과냉도, 계면에너지 비, 시간 슬라이더를 실시간으로 조절하여 2D 원자 배열, 3D 결정립, 그래프를 시뮬레이션하고 시각화할 수 있습니다.

🌐 **라이브 데모 확인하기:** [https://csmsm0518.github.io/quasicrystal-sim/](https://csmsm0518.github.io/quasicrystal-sim/)

---

## 🚀 주요 기능 (Key Features)

- **2D 원자 배열 시뮬레이션:** 실시간으로 격자와 준결정 패턴의 원자 조밀 구조 변화 시각화
- **3D 결정립 성장 및 형성 모델링:** 매개변수 변화에 따른 결정립의 성장 양상 모니터링
- **실시간 그래프 피드백:** 시뮬레이션 데이터 수치 변동을 직관적인 그래프로 추적
- **인터랙티브 파라미터 제어:**
  - 과냉도 (Undercooling)
  - 계면에너지 비 (Interfacial Energy Ratio)
  - 시간 슬라이더 (Time Evolution)

## 💻 로컬 실행 방법 (How to Run Locally)

별도의 복잡한 패키지 설치 없이 브라우저에서 바로 실행할 수 있습니다.

1. 본 저장소를 클론(Clone)하거나 다운로드합니다.
   ```bash
   git clone https://github.com
   ```
2. 프로젝트 폴더로 이동합니다.
   ```bash
   cd quasicrystal-sim
   ```
3. `index.html` 파일을 더블 클릭하거나 브라우저 창으로 드래그하여 실행합니다.
